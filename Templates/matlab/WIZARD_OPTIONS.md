# Wizard Configuration Options

This document outlines the components of a generated MATLAB tool, categorized into "Core" (mandatory) and "Optional" features. This serves as a specification for the **ToolWizard** configuration UI.

## 1. Core Components (Always Generated)
Every tool generated by the wizard will automatically include these components. They form the minimum viable structure for a compliant engineering tool.

*   **Root Folder**: `{{ToolName}}/`
*   **Package Structure**: `+{{tool_package}}/`
*   **Main Class**: `{{ToolName}}.m` (Inherits from `ToolBasis`)
*   **Help File**: `Contents.m`
*   **Data Keys**: `+{{tool_package}}/DataKeys.m`
*   **Input Schema**: `+{{tool_package}}/+inputs/get_schema.m` (Basic properties like `runName`, `targetDir`)
*   **Testing Infrastructure**: `+{{ToolName}}Test/{{ToolName}}_Test.m`

## 2. Optional Components (Wizard Selections)
The user can choose to include these features based on their specific needs.

### A. Input/Output Modules
**Option: "Include Input Loader"**
*   **Description**: Adds logic to read external input files (e.g., FEM models, load files) and map them to the Data Model.
*   **Files Added**: `+{{tool_package}}/+io/LoadExternalFilesStep.m`
*   **Runner Effect**: Adds `LoadExternalFilesStep` to the execution sequence.

**Option: "Include Output Writer"**
*   **Description**: Adds logic to save results to a file (type specified by `output_type`).
*   **Files Added**: `+{{tool_package}}/+io/WriteFilesStep.m`
*   **Runner Effect**: Adds `WriteFilesStep` to the execution sequence.

### B. Logic Structure
**Option: "Standard Calculation Step"**
*   **Description**: Adds a placeholder step for the main engineering calculations.
*   **Files Added**: `+{{tool_package}}/+model/MainModelStep.m`
*   **Runner Effect**: Adds `MainModelStep` to the execution sequence.

### C. Advanced Validation
**Option: "Extended Input Checks"**
*   **Description**: Adds separate files for complex post-parsing validation and data manipulation. Recommended for complex tools.
*   **Files Added**:
    *   `+{{tool_package}}/+inputs/PostParseChecks.m`
    *   `+{{tool_package}}/+inputs/PostParseManipulations.m`
*   **Main Class Effect**: `{{ToolName}}.m` will call these classes in `do_post_parse_checks` and `do_post_parse_manipulations`.

### D. Batch Processing
**Option: "Enable Batch Runner"**
*   **Description**: Enables running the tool on multiple input files via a batch override mechanism.
*   **Files Added**:
    *   `+{{tool_package}}/+batch/Runner.m`
*   **Main Class Effect**: Adds `run_batch` method to `{{ToolName}}.m`.

### E. Documentation & Git
**Option: "Include Documentation Site"**
*   **Description**: Sets up a `mkdocs` structure for generating a static documentation website.
*   **Files Added**:
    *   `mkdocs.yml`
    *   `docs/index.md`
    *   `docs/user_guide.md`

**Option: "Include Pre-commit Config"**
*   **Description**: Adds a configuration file to enforce coding standards (e.g., `miss_hit`).
*   **Files Added**: `.pre-commit-config.yaml`
