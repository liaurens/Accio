# Tutorials

The pages in this section of the documentation are aimed at the newcomer to USAIN.
The tutorials are learning-oriented and provide practical steps to help you get started quickly.
It is assumed that you have the latest MATLAB release.
This can easily be verified in MATLAB by running the following command:

``` matlab
which USAIN
```

## Available tutorials

- [Your first USAIN run](./first-run.md): Play around with an existing file to get familiar with USAIN.
- [Review results](./reviewing.md): Steps on interpreting and reviewing USAIN results.
- [Include USAIN in TEXACO](./texaco.md): Integrating USAIN in the TEXACO tool chain.

!!! tip
    It is recommended to work through the tutorials in the order as listed above.
