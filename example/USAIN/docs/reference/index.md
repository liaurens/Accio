# Reference guides

The reference guides are *technical descriptions* of the tool and how to operate it.
The guides have one job only: to describe.

- [User commands](./commands.md): Lists the commands needed to run USAIN.
- [Input file](./inputfile.md): Describes the various sections of the input file.
- [Expert inputs](./expert-inputs.md): Tweak the details of your flanges with these expert inputs.
- [Fastener properties](./fastener-props.md): An overview of bolt/nut/washer/tool/etc. properties used in USAIN.
- [Japanese specific settings](./Japan-design.md): An overview of inputs specifically for the Japanese market or which are deviating from the "rest of the world" design.
